# Testing

FavGCalSchedulerClone の自動テスト、実機比較メモ、手動確認項目をまとめます。

## 自動テスト

リポジトリ直下で以下を実行します。

```powershell
dotnet build .\FavGCalSchedulerClone.sln
dotnet test .\FavGCalSchedulerClone.sln
```

## FavGCalScheduler 実機確認メモ

- `C:\Program Files (x86)\FavGCalScheduler\FavGCalScheduler.exe` を起動し、月グリッド、上部メニュー、月移動バー、下部タブ一覧の構造を確認。
- 月セル内の予定は、薄い枠付きの横長ラベルで表示され、時刻付き予定は先頭に時刻が表示される。
- ToDo は左端のチェック枠/チェック表示、優先度、進捗で通常予定と区別される。
- カレンダー上の右クリックメニューから、予定追加、ToDo追加、編集、削除、一覧表示に移れる。
- ToDo未処理一覧では左端のチェック操作で進捗を100%にできる。
- Clone側では青基調テーマ、右サイドの選択日予定/未完了タスク表示、既存メニュー構成を維持しつつ、予定ラベル、ToDo表示、行ダブルクリック編集を合わせている。
- FavGCalScheduler の下部タブ一覧そのもの、右クリックメニュー、天気表示、アイコン体系は完全一致を目的とせず、Clone側の既存構成を優先している。

## 手動テスト

### カレンダー操作・編集

- [ ] 月表示で今日以外の日付をクリックし、選択日が切り替わる。
- [ ] 右側の選択日の予定一覧が切り替わる。
- [ ] 空白セルをダブルクリックして新規予定を追加できる。
- [ ] 月表示の予定ラベルをダブルクリックして編集できる。
- [ ] 週表示の予定ラベルをダブルクリックして編集できる。
- [ ] 日表示の予定行をダブルクリックして編集できる。
- [ ] 未完了タスクをダブルクリックして編集できる。
- [ ] 検索結果から予定をダブルクリックして編集できる。
- [ ] DataGridの空白部分、ヘッダー、スクロールバーをダブルクリックしても予定編集が開かない。
- [ ] 日付セルを右クリックして予定追加、ToDo追加、スケジュール一覧を開ける。
- [ ] 予定ラベルを右クリックして編集、削除、ToDo完了を実行できる。
- [ ] スケジュール一覧/検索結果の空白部分をダブルクリックしても予定編集が開かない。
- [ ] 月/週表示の通常予定、複数日予定、ToDoを別の日セルへドラッグすると日付が移動し、色、期間、ToDo進捗が維持される。
- [ ] 予定/ToDo編集画面で複数行の内容を入力して再保存しても改行が維持され、ToDo編集時の内容欄には内部 `#todo...%` マーカーが表示されない。
- [ ] 予定/ToDo編集画面のサイズと各入力欄の位置・幅が元アプリの編集画面に近く、最下部の日付情報が選択日に追従する。

### ToDo

- [ ] ToDoの優先度/進捗率をUIから編集できる。
- [ ] 未完了タスク一覧の左端チェックをクリックすると進捗100%になり、未完了一覧から消える。
- [ ] ToDoを完了にすると未完了一覧から消える。
- [ ] 未完了ToDoは期限日のローカル時刻08:15にアプリ内で1回通知される。
- [ ] 08:15に停止していても期限日当日の起動時には遅延通知し、翌日以降は通知しない。
- [ ] ToDoではGoogleのpopup/email/既定通知を使用せず、同期時に無効化される。

### 表示・ナビゲーション

- [ ] 「設定 > フォーカス解除時に今日へ戻す」は初期状態でONになり、アプリ設定を開かずに切り替えられる。
- [ ] ONの場合、今日以外の日付を選択して他のアプリへ切り替えると、選択日が今日へ戻る。
- [ ] OFFの場合、今日以外の日付を選択して他のアプリへ切り替えても、選択日が維持される。
- [ ] ON/OFFの状態はアプリを再起動しても維持される。
- [ ] `Home` キーまたは上部の期間表示を操作すると、ON/OFFに関係なく今日へ移動できる。
- [ ] 複数日にわたる予定は月/週表示で連結ラベルになり、週をまたぐ場合は各週の先頭で件名が再表示される。
- [ ] ラベルのホバーで予定詳細が表示され、継続部分のクリックで該当日が選択され、ダブルクリックで予定またはToDoを編集できる。
- [ ] 日セルはラベル上を含めたホバーで枠が強調され、クリックした日の右側予定一覧が表示される。
- [ ] 月/週表示で選択した連結ラベルは同一週内のバー全体が強調され、ラベルのダブルクリック後に新規予定登録が誤表示されない。
- [ ] 選択した白・薄青・薄緑・濃色ラベルは、太枠に加えて背景色が濃くなり、件名が読みやすいまま選択状態を判別できる。

### ラベル色・タグ・FavGCalScheduler取り込み

- [ ] 元アプリで白、薄青、薄緑を含む複数色の予定を作成または変更し、Cloneへ取り込むと月表示の予定ラベル色が一致する。
- [ ] 取り込んだ色値 `1..11` の予定を編集すると対応色が選択され、白の予定は「標準（白）」として表示される。
- [ ] 取り込んだ予定を再保存してもラベル色が維持される。
- [ ] 「既存予定のラベル色を元データで修復する」を有効にして再取り込みすると、旧解析で誤色保存された通常予定とToDoのラベル色が修正される。
- [ ] 「既存ToDoの内容を元データで修復する」を有効にして再取り込みすると、旧処理で一行化されたToDo本文の改行が元データどおりに復元される。
- [ ] 日セル用 directive は `#holiday` と `#workday` のみで、予定ラベル色は変更しない。
- [ ] 日セル用 directive は予定の内容欄にタグ名だけの行として入力し、`#holiday` は休日色、`#workday` は土日を含め平日色になり、その指示予定自体はカレンダーおよびサイド一覧へ表示されない。
- [ ] 右側の選択日の予定、未処理ToDo、処理済みToDo、一覧/検索結果でも件名ラベル色が月表示と一致する。

### 設定・通知・タスクトレイ

- [ ] 設定画面で起動ビュー、ToDo開始タブ、曜日開始日、文字サイズ、透明度、ToDo表示期間を変更し、再起動後も維持される。
- [ ] 通常予定の件名/場所履歴候補が利用でき、履歴設定から削除できる。
- [ ] 通知音のテスト再生とWindows通知切替が動作し、Google自動同期設定が保存される。
- [ ] 通知はアプリ起動中またはタスクトレイ常駐中に動作する。
- [ ] アプリを完全に終了している間はローカル通知サービスが動作せず、通知されない。
- [ ] 通常予定の通知設定は従来どおり動作する。
- [ ] 起動中は当日の日付を表示するタスクトレイアイコンが存在する。
- [ ] 多重起動は拒否される。
- [ ] 閉じるボタンでは終了せず、トレイメニューの終了からのみ終了できる。

### Google同期

- [ ] Googleカレンダー設定で手動同期前プレビュー、同期診断ログ、競合時の扱いを切り替えられる。
- [ ] 手動同期プレビューではGoogleへ送信、Googleから取得、削除、競合、エラー候補を確認してから同期できる。
- [ ] ローカルとGoogleの同時編集がある場合、既定ではローカル未同期変更を上書きせず競合として同期診断に記録される。
- [ ] 同期診断画面で最終同期結果、対象カレンダー、syncToken有無、未同期件数、直近ログを確認できる。

## 仕様対象外データに対する参考確認

繰り返し予定の作成・詳細編集は本アプリの正式な仕様対象外です。Google側に既存の繰り返し予定がある場合の防御的な挙動を確認する場合のみ、次を参考確認として扱います。

- [ ] 繰り返し予定をドラッグした場合に対象範囲の確認が表示され、キャンセル時には移動しない。

この項目は繰り返し予定機能のサポートを意味するものではありません。
