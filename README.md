# FavGCalSchedulerClone

FavGCalScheduler の操作感に近づけることを目標にした、個人利用向けの Windows カレンダーアプリです。Google カレンダーの通常予定をローカル SQLite に同期し、月表示、1 日の予定、7 日先までの予定、ToDo 候補を表示します。

## 現在の実装範囲

- FavGCalScheduler 風の日本語メニュー、月ナビゲーション、月間カレンダー、下部タブ UI
- ローカル SQLite キャッシュによる予定の保存、編集、削除
- Google Calendar API による `primary` カレンダーとの双方向同期
- `#holiday` を含む予定の休日色表示
- `#work`、`#private`、`#important`、`#holiday` の日セル背景色分けと表示切り替え
- Google同期またはFavGCalScheduler取り込みで得た予定ラベル色の表示・編集
- 予定ラベル色の月/週/日表示、選択日の予定、未処理/処理済ToDo、一覧/検索への統一表示
- 本アプリ独自タグ `#workday` による土日祝日の平日色表示
- FavGCalScheduler の `#todoA56%` 形式によるToDo優先度、進捗、未処理/処理済み表示
- スケジュール追加、ToDo追加、スケジュール一覧、検索、アプリ設定、バージョン情報の軽量ダイアログ
- ローカル SQLite DB の ZIP バックアップと安全なリストア
- 現在表示年の予定 CSV エクスポートと新規追加インポート
- 現在表示月の月間カレンダー印刷プレビューと印刷
- DPAPI による Google OAuth トークンのユーザー単位保護
- 元アプリに準じたアプリ/表示/ToDo/履歴/通知/Google設定タブ、入力履歴、通知音、自動同期

## タグ仕様

| タグ | 種別 | 動作 |
| --- | --- | --- |
| `#holiday` | FavGCalScheduler互換 | その日のカレンダー表示色を休日色にします。 |
| `#workday` | 本アプリ独自 | 土日祝日でも、その日のカレンダー表示色を平日色にします。`#holiday` と同じ日にある場合は `#workday` を優先します。 |
| `#todoA56%` | FavGCalScheduler互換 | ToDoとして扱います。英字は優先度、数字は進捗率です。進捗が100%未満なら未処理、`#todo100%` や `#todoA100%` は処理済みとして表示します。 |
| `#work` / `#private` / `#important` | 本アプリ表示タグ | その日の日セル背景色を優先度順に切り替えます。予定ラベル色は変更しません。 |

ToDoタグはGoogleカレンダー上では通常の予定タイトルまたは説明欄内の文字列として残ります。本アプリでToDo進捗を更新すると、説明欄内の既存 `#todo...%` を置き換え、同じToDoタグを二重に追加しないようにします。予定ラベル色はGoogle互換の `ColorId` で保持し、色なしの値は元アプリと同じ白ラベルとして表示します。

## Google OAuth 設定

このアプリは個人利用前提です。Google の審査申請、公開用プライバシーポリシー、ブランド審査は行っていません。

1. Google Cloud で個人用プロジェクトを作成します。
2. Google Calendar API を有効化します。
3. OAuth 同意画面を `External` で作成します。
4. 個人利用では `In production` にします。`Testing` のままだと refresh token が短期間で期限切れになる場合があります。
5. OAuth client ID を `Desktop app` として作成し、JSON をダウンロードします。
6. アプリの `カレンダー` タブで JSON を選択し、Google 認証を実行します。
7. 未検証アプリ警告が表示された場合は、本人が内容を確認して通過します。

OAuth client JSON はリポジトリや配布 ZIP に含めないでください。

- `C:\Program Files (x86)\FavGCalScheduler\FavGCalScheduler.exe` を起動し、月グリッド、上部メニュー、月移動バー、下部タブ一覧の構造を確認しました。
- 月セル内の予定は、薄い枠付きの横長ラベルで表示され、時刻付き予定は先頭に時刻が出ます。
- ToDoは左端のチェック枠/チェック表示、優先度、進捗で通常予定と見分けられます。
- カレンダー上の右クリックメニューから、予定追加、ToDo追加、編集、削除、一覧表示に移れます。
- ToDo未処理一覧では左端のチェック操作で進捗を100%にできます。
- Clone側では青基調テーマ、右サイドの選択日予定/未完了タスク表示、既存メニュー構成は維持し、予定ラベル、ToDo表示、行ダブルクリック編集を合わせています。
- 完全一致していない点: FavGCalSchedulerの下部タブ一覧そのもの、右クリックメニュー、天気表示、アイコン体系はClone側の既存構成を優先して未移植です。

- スケジュール一覧/検索結果の空白部分をダブルクリックしても予定編集が開かない

- ToDoを完了にすると未完了一覧から消える

- 元アプリで白、薄青、薄緑を含む複数色の予定を作成または変更し、Cloneへ取り込むと月表示の予定ラベル色が一致する
- 取り込んだ色値 `1..11` の予定を編集すると対応色が選択され、白の予定は「標準（白）」として表示される
- 取り込んだ予定を再保存してもラベル色が維持される
